# Apollo Releases

This repo hosts Apollo's installer downloads and auto-update assets only.
There is no source code here — Apollo's source lives in a private repository.

## Download

Get the latest installer: [Last ned Apollo](https://github.com/Xahnolox/Apollo-Releases/releases/latest/download/Apollo_Setup.zip)

1. Extract the ZIP
2. Run `Install Apollo.vbs`
3. Follow the on-screen instructions

Apollo updates itself automatically after that — no need to check back here.
